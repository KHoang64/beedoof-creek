# Brown Duck Blender Export

Import `Brown Duck.fbx` into Blender with **File > Import > FBX**.

Included textures:

- `Duck Brown.png` — body texture
- `Duck Feather - Brown.png` — feather texture

The FBX contains the original rig and animation data from the Unity asset. Keep the three files together so texture references can be relinked if Blender does not resolve them automatically.
